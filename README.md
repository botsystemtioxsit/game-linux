# Косынка — пасьянс для Linux

Классический пасьянс «Косынка» (Klondike Solitaire) с графическим интерфейсом.
Написан на Python и Tkinter, работает почти на любом Linux: Ubuntu, Debian, Mint, Fedora, Arch, openSUSE и других.

## Возможности

- Перетаскивание карт мышью, в том числе целых стопок
- Двойной щелчок отправляет карту в дом или на подходящее место
- Правая кнопка мыши собирает в дом все подходящие карты
- Сдача по 1 или по 3 карты
- Неограниченная отмена ходов
- Очки, счётчик ходов и таймер
- Автоматическое доигрывание, когда все карты открыты
- «Водопад» карт после победы
- Статистика: партии, победы, лучшее время и лучший счёт
- Масштабирование под размер окна

## Установка

Сначала скачайте проект:

```sh
git clone https://github.com/botsystemtioxsit/game-linux.git
cd game-linux
```

### Вариант 1. Установщик (любой дистрибутив)

```sh
./install.sh
```

Игра установится только для вас, в `~/.local`, без прав администратора, и появится в меню приложений в разделе «Игры».
Если в системе нет модуля `tkinter`, установщик сам предложит его поставить.

Чтобы установить для всех пользователей: `sudo ./install.sh --system`.

Удаление: `./uninstall.sh` (или `sudo ./uninstall.sh --system`).

### Вариант 2. Пакет .deb (Debian, Ubuntu, Linux Mint)

```sh
./build-deb.sh
sudo apt install ./dist/solitaire-linux_1.0.0_all.deb
```

`apt` сам доустановит зависимости (`python3`, `python3-tk`).
Удаление: `sudo apt remove solitaire-linux`.

### Вариант 3. Запуск без установки

```sh
python3 -m solitaire
```

Если появится ошибка про `tkinter`, установите его:

| Дистрибутив              | Команда                             |
|--------------------------|-------------------------------------|
| Ubuntu / Debian / Mint   | `sudo apt install python3-tk`       |
| Fedora                   | `sudo dnf install python3-tkinter`  |
| Arch / Manjaro           | `sudo pacman -S tk`                 |
| openSUSE                 | `sudo zypper install python3-tk`    |

## Правила

Цель — разложить все карты в четыре стопки «дома» (справа вверху) по мастям, от туза до короля.

- В колонках карты кладутся по убыванию, чередуя цвет: красная на чёрную, чёрная на красную.
- На пустую колонку можно положить только короля.
- Щелчок по колоде (слева вверху) открывает новые карты. Когда колода кончится, щелчок переворачивает сброс обратно.

## Управление

| Действие                          | Клавиша / мышь              |
|-----------------------------------|-----------------------------|
| Переместить карты                 | перетащить левой кнопкой    |
| Отправить в дом / на лучшее место | двойной щелчок              |
| Собрать всё возможное в дом       | правая кнопка мыши          |
| Открыть карту из колоды           | щелчок по колоде или Пробел |
| Отменить ход                      | Ctrl+Z или Backspace        |
| Новая игра                        | F2 или Ctrl+N               |
| Сыграть эту раздачу заново        | Ctrl+R                      |
| Выход                             | Ctrl+Q                      |

Чтобы сыграть конкретную раздачу, укажите её номер: `solitaire-linux 12345`.

Настройки и статистика хранятся в `~/.config/solitaire-linux/settings.json`.

## Для разработчиков

Тесты игровой логики:

```sh
python3 -m unittest discover -s tests
```

Логика игры находится в `solitaire/game.py` и не зависит от интерфейса. Интерфейс находится в `solitaire/ui.py`.
